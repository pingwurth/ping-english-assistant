# 生词本功能设计方案

## 一、需求概述

用户在播放器字幕区域选中英文文本（单词/词组/短句）后，浮现浮动气泡按钮，点击后弹窗选择目标生词本，支持创建多个生词本进行分类管理。

### 核心功能

1. **选词添加**：在字幕区域选中任意英文文本（单词、词组、短句），浮现「添加到生词本」气泡
2. **多生词本**：支持创建多个生词本（如「四级词汇」「考研阅读」「日常口语」），添加时选择目标生词本
3. **生词本管理**：独立页面查看、管理所有生词本及词条
4. **LLM 释义**（可选增强）：利用已有 LlmExplainRequest 合约，为词条填充释义

## 三、数据模型

### VocabBook（生词本）

```typescript
export interface VocabBook {
  id: string              // 唯一 ID（crypto.randomUUID()）
  name: string            // 生词本名称
  createdAt: number
  updatedAt: number
}
```

### VocabEntry（词条）

```typescript
export interface VocabEntry {
  id: string              // 唯一 ID
  text: string            // 选中的文本（单词/词组/短句）
  context: string         // 所在句子原文
  materialId: string
  sentenceIndex: number
  bookId: string          // 所属生词本 ID
  addedAt: number
  definition?: string     // 可选 LLM 释义
}
```

### 约定

- 预置默认生词本：`id = 'default'`，`name = '默认生词本'`
- 一个词条只属于一个生词本（不做多对多）
- 同一生词本内 `text` 去重（大小写不敏感）

### IDB Key 设计

```typescript
// schema.ts 新增
vocabBook: (bookId: string) => `vocabbook:${bookId}`
vocabEntry: (entryId: string) => `vocabentry:${entryId}`
```

- `vocabbook:{id}` → 存储 `VocabBook` 对象
- `vocabentry:{id}` → 存储 `VocabEntry` 对象

## 四、交互流程

### 4.1 选词 → 添加流程

```
用户在字幕 <p> 中拖选文本
        │
        ▼
  有选中文本？ ──── 否 ──→ 不响应
        │
        是
        ▼
  选中文本 trim 后长度 > 0？ ──── 否 ──→ 不响应
        │
        是
        ▼
  选中文本完全落在当前句子 textEn 范围内？
        │                 │
        是                否 → 不响应（跨句选择忽略）
        ▼
  在选中位置附近浮现气泡
  ┌─────────────────────────┐
  │  selected text          │
  │  「+ 添加到生词本」       │  ← 未收录
  │  「✓ 已添加到 xxx」      │  ← 已收录
  └─────────────────────────┘
        │
    点击「+ 添加到生词本」
        │
        ▼
  弹出「生词本选择」弹窗
  ┌──────────────────────────┐
  │  添加到生词本              │
  │                          │
  │  选择生词本：              │
  │  ○ 默认生词本             │
  │  ○ 四级词汇               │
  │  ○ 考研阅读               │
  │                          │
  │  [+ 新建生词本]           │
  │                          │
  │       [取消]  [确定]      │
  └──────────────────────────┘
        │
    点击确定
        │
        ▼
  写入 IDB
  气泡变为「✓ 已添加到 "四级词汇"」
  2 秒后气泡自动消失
```

### 4.2 气泡关闭条件

- 点击气泡外部区域
- 页面滚动
- 按 Escape 键
- 选中文本清空

### 4.3 移动端适配

- 使用 `touchend` + `selectionchange` 事件
- 长按触发选词（与原生文本选择行为一致）

## 五、UI 设计

> 详见 [生词本 UI 设计](../生词本UI设计.html)

### 5.1 选词气泡

- 定位：跟随选中文本位置，上方或下方浮动
- 内容：选中文本 + 操作按钮
- 样式：`fixed` 定位，`z-50`，圆角卡片，阴影
- 边界检测：超出视口时自动调整方向

### 5.2 生词本选择弹窗

- 居中模态弹窗（使用 shadcn Dialog）
- 生词本列表（radio 选择）
- 底部「新建生词本」按钮
- 确定/取消操作

### 5.3 生词本页面

- 路由：`/vocabulary`
- 左侧：生词本列表（可切换）
- 右侧：当前生词本的词条列表
- 每个词条：文本、来源句子、添加时间、删除按钮
- 空状态引导

## 八、选词匹配逻辑

```typescript
function isValidSelection(
  selection: string,
  sentenceText: string
): boolean {
  const normalized = selection.trim().replace(/\s+/g, ' ')
  if (normalized.length === 0) return false
  // 检查选中文本是否为句子的子串（大小写敏感，保留原样）
  return sentenceText.includes(normalized)
}
```

## 九、风险与注意事项

| 风险 | 级别 | 应对 |
|------|------|------|
| 移动端无法触发 `mouseup` 选词 | 中 | 同时支持 `touchend` + `selectionchange` |
| 选中文本含多余空格导致匹配失败 | 低 | 匹配前 normalize（trim + collapse whitespace） |
| 跨句选择 | 低 | 校验选中文本是否在当前句子范围内 |
| 气泡位置超出视口 | 低 | 边界检测，自动翻转方向 |
| 选词与播放器点击事件冲突 | 中 | 仅在有选中文本时响应 `mouseup` |
| 同一文本在不同语境含义不同 | 低 | v1 保留首次上下文，后续可扩展 |

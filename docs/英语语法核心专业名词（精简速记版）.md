## 一、词类 Parts of speech

1. Noun 名词：可数 countable / 不可数 uncountable；集合 collective；抽象 abstract
2. Pronoun 代词：人称 personal、物主 possessive、反身 reflexive、关系 relative、不定 indefinite
3. Adjective 形容词：原级 positive、比较级 comparative、最高级 superlative
4. Adverb 副词
5. Verb 动词
 vt. Transitive verb 及物动词；vi. Intransitive verb 不及物动词
 Linking verb 系动词；Auxiliary verb 助动词；Modal verb 情态动词
 Finite verb 限定动词 (谓语)；Non‑finite verb 非限定动词 (非谓语)
  ・Infinitive 不定式 to‑do
  ・Gerund 动名词 doing
  ・Participle 分词：Present participle 现在分词 doing / Past participle 过去分词 done
6. Preposition 介词
7. Conjunction 连词：并列 coordinating；从属 subordinating
8. Article 冠词：定 definite (the)、不定 indefinite (a/an)、零冠词 zero article
9. Determiner 限定词；Quantifier 数量词

## 二、句子成分 Sentence elements

- Subject (S) 主语；Predicate 谓语；Object (O) 宾语：Direct object 直接宾语 / Indirect object 间接宾语
- Predicative 表语；Attribute 定语；Adverbial 状语
- Complement 补语：Subject complement 主语补语 / Object complement 宾语补语
- Appositive 同位语

五大句型：SV 主谓、SVO 主谓宾、SVP 主系表、SVOO 主谓双宾、SVOC 主谓宾补

## 三、分句与句子类型

- Main clause / Independent clause 主句 / 独立分句
- Subordinate clause / Dependent clause 从句 / 从属分句

1. Simple sentence 简单句
2. Compound sentence 并列句
3. Complex sentence 复合句
4. Compound‑complex sentence 并列复合句

按用途：Declarative 陈述句；Interrogative 疑问句；Imperative 祈使句；Exclamatory 感叹句

## 四、三大从句 Clauses

1. Noun‑clause 名词性从句：主语从句 subject‑clause、宾语从句 object‑clause、表语从句 predicative‑clause、同位语从句 appositive‑clause
2. Relative / Attributive clause 定语从句：限制性 restrictive；非限制性 non‑restrictive
3. Adverbial clause 状语从句（时间 / 原因 / 条件 / 让步 / 目的 / 结果 / 比较 / 方式）

## 五、时态、语态、语气

- Tense 时态；Aspect 体；Voice 语态：Active 主动；Passive 被动
- Mood 语气：Indicative 陈述；Imperative 祈使；Subjunctive 虚拟

## 六、特殊语法现象

- Concord / Agreement 主谓一致
- Inversion 倒装：Full inversion 完全倒装；Partial inversion 部分倒装
- Ellipsis 省略；Emphasis 强调；Word‑order 语序；Possessive / Genitive 所有格

## 记忆使用小建议

1. 优先背**句子成分 + 非谓语 + 三大从句**，做长难句分析高频用到；
2. 看语法解析的时候遇到术语就回来对照，不用死记硬背，结合例句理解；
3. 阅读语法书、真题解析，看懂这些术语才能读懂解析逻辑。

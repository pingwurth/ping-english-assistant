# 生词训练功能 — 开发设计文档

> 基于「生词训练功能设计.md」分析总结，对齐实际代码结构，供开发直接使用。

---

## 一、功能概述

在现有生词本基础上，新增**生词专项训练**能力：用户选择若干生词 → 系统从原始字幕中检索上下文句 → 自动编排训练课程（填空/听写/跟读/报告） → 结果写入独立的训练记录。

**核心价值**：解决「查了就忘」问题，让生词从被动收集变为主动内化。

## 三、数据模型

### 3.1 类型扩展 (`types/vocabulary.ts`)

```ts
// === 新增：熟练度等级 ===
export type ProficiencyLevel = 'new' | 'familiar' | 'mastered'

// === 扩展 VocabEntry（新增 2 个可选字段，向后兼容）===
// 在现有 VocabEntry 接口中追加：
//   reviewStage?: number          // 训练推进阶段 0-5（默认 0）
//   lastTrainedAt?: number        // 最近一次训练时间戳

// === 新增：训练句 ===
export interface VocabDrillSentence {
  materialId: string
  sentenceIndex: number
  textEn: string
  textZh: string | null
  startMs: number
  endMs: number
  matchedWord: string             // 命中的生词原文
  matchStart: number              // 在 textEn 中的起始字符位置
  matchEnd: number                // 在 textEn 中的结束字符位置
}

// === 新增：训练课程 ===
export type DrillMode = 'fill-blank' | 'dictation' | 'read-aloud' | 'report'

export interface VocabDrill {
  id: string                      // `drill:${Date.now()}`
  wordIds: string[]               // 参与的生词 ID
  sentences: VocabDrillSentence[] // 已去重、排序的训练句
  mode: DrillMode
  currentIndex: number            // 当前句索引
  createdAt: number
}

// === 新增：单句训练结果 ===
export interface VocabSentenceResult {
  sentenceIndex: number
  mode: DrillMode
  score: number                   // 0-100
  correct: boolean
  detail: Record<string, unknown>
  completedAt: number
}

// === 新增：训练记录 ===
export interface VocabTrainingRecord {
  id: string                      // `vtr:${Date.now()}`
  drillId: string
  wordIds: string[]
  mode: DrillMode
  sentenceResults: VocabSentenceResult[]
  totalScore: number              // 平均分
  timeSpentMs: number
  createdAt: number
}

// === 新增：统计视图模型 ===
export interface VocabStatsOverview {
  totalWords: number
  newWords: number
  familiarWords: number
  masteredWords: number
  sevenDayTrend: number[]         // [D-6, D-5, ..., D-0]
  trainedToday: number
  avgScoreLast7: number
}

export interface WeakWordRow {
  entry: VocabEntry
  avgScore: number
  failCount: number
  lastScore: number
}

export interface ForgettingRiskRow {
  entry: VocabEntry
  lastTrainedAt: number
  daysSince: number
  lastScore: number
}

// === 新增：熟练度判定工具函数 ===
export function getProficiency(entry: VocabEntry): ProficiencyLevel {
  const stage = entry.reviewStage ?? 0
  if (stage >= 4) return 'mastered'
  if (stage >= 2) return 'familiar'
  return 'new'
}
```

## 四、模块设计

### 4.1 上下文句检索 (`core/vocab-training/context-search.ts`)

**职责**：从 IndexedDB 扫描所有素材字幕，匹配生词文本。

```ts
// 输入
interface SearchContextOptions {
  words: string[]                 // 待检索生词文本列表（已小写）
  materialIds?: string[]          // 可选：限定素材范围
  limit?: number                  // 每个词最多返回句数（默认 5）
}

// 输出
interface ContextSearchResult {
  word: string
  sentences: VocabDrillSentence[]
}

// 核心逻辑
async function searchContexts(options: SearchContextOptions): Promise<ContextSearchResult[]>
```

**算法**：
1. 获取所有素材 ID：`recordsStore.allKeys()` → 过滤 `material:` 前缀
2. 遍历素材，`getMaterialRecord(id)` 获取 `subtitleData.sentences`
3. 对每个 `SubtitleSentence.textEn` 做大小写不敏感匹配
4. 匹配成功时记录 `matchStart` / `matchEnd`（用于填空渲染）
5. 按 `materialId + sentenceIndex` 去重
6. 每词最多返回 `limit` 句，优先选最短句（信息密度高）

**注意**：
- `SubtitleSentence.words` 已分词去标点，但匹配需在原始 `textEn` 上做（保留标点位置）
- 使用 `textEn.toLowerCase().indexOf(word.toLowerCase())` 匹配
- 不调用任何 AI 服务，纯本地操作

### 4.2 课程编排 (`core/vocab-training/drill-builder.ts`)

**职责**：从命中句中筛选、排序，生成 `VocabDrill`。

```ts
function buildDrill(params: {
  sentences: VocabDrillSentence[]
  wordIds: string[]
  mode: DrillMode
  maxSentences?: number           // 默认 10
}): VocabDrill
```

**筛选策略**：
1. 优先保留「多词命中句」（一句含多个生词）
2. 按句长升序（短句优先）
3. 截断至 `maxSentences`

### 4.3 填空题生成 (`core/vocab-training/blank-generator.ts`)

```ts
function generateBlank(textEn: string, matchStart: number, matchEnd: number): {
  before: string
  blank: string
  after: string
  blankLength: number
}
```

将命中词替换为 `___`，返回三段文本供渲染。

### 4.4 训练进度推进 (`core/vocab-training/progress-updater.ts`)

```ts
async function updateWordProgress(
  entryId: string,
  score: number,
  correct: boolean
): Promise<void>
```

**阶段推进规则**：
- 连续 `correct`：`reviewStage` +1（上限 5）
- `incorrect`：重置为 0
- 用 `score >= 70` 判定 `correct`

**调用**：更新 `vocab-store` 中的 `reviewStage` 和 `lastTrainedAt`。

### 4.5 统计聚合 (`stores/vocab-stats-store.ts`)

**新 Store**，从 `recordsStore` 聚合统计。

```ts
interface VocabStatsState {
  overview: VocabStatsOverview | null
  weakWords: WeakWordRow[]
  forgettingRisks: ForgettingRiskRow[]
}

const vocabStatsStore = createStore<VocabStatsState>({ ... })

async function refreshVocabStats(): Promise<void>
```

**数据来源**：
- `vocabStore.entries` → 熟练度分布
- `recordsStore.allKeys()` → 扫描 `vocabtrain:` 前缀 → 解析 `VocabTrainingRecord`
- 按 `createdAt` 过滤 7 天内记录 → 趋势/均分
- 按 `wordIds` 聚合 → 薄弱词排行
- 按 `lastTrainedAt` 计算天数 → 遗忘风险

### 5.4 各页面要点

#### VocabDrillSetup（课程配置）

- 左侧：生词列表（checkbox 多选），支持全选/按书筛选/按熟练度筛选
- 右侧：从选中词检索到的上下文句预览（最多 50 句），显示来源素材名
- 底部：模式选择卡片（填空/听写/朗读/报告）+ 「开始训练」按钮
- 空状态：选中词均无命中句时，提示「这些词暂无对应字幕句，试试先导入包含这些词的素材」

#### VocabFillBlank（填空训练）

- 布局：上下分栏（与现有 puzzle.tsx 风格一致）
  - 上方：英文句（命中词显示为 `___`）+ 中文翻译
  - 下方：4 个候选项（1 正确 + 3 干扰）
- 交互：点击选项 → 即时反馈（绿/红）→ 2 秒后自动下一句
- 干扰项来源：同 `VocabDrillSentence[]` 中其他句的 `matchedWord`

#### VocabDictation（听写训练）

- 复用 `core/training/diff.ts` 的 `diffWords()` + `sentenceAccuracy()`
- 布局：音频播放区 + 输入框 + 评分结果
- 音频：复用现有 `SentencePlayer.playRange(materialId, startMs, endMs)`

#### VocabReadAloud（朗读训练）

- 复用 `SoeService.evaluate(audio, refText, 'sentence')`
- 布局：原文展示 + 录音按钮 + 评分面板（准确度/流利度/完整度）

#### VocabDrillReport（综合报告）

- 本地评分先行显示（无需等待 AI）
- AI 报告通过 `ShadowingReportService` 或 `RecitationReportService` 流式生成
- 结构化卡片：总分、各维度分、正确率
- AI 分析：流式文本，语法纠错+例句+扩展

#### VocabStats（统计面板）

- 熟练度分布饼图/条形图（new/familiar/mastered）
- 7 日趋势折线图（训练次数 + 平均分）
- 薄弱词排行榜（按均分升序，限前 10）
- 遗忘风险列表（7 天未训练 + 最后得分 <80）

## 九、设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 训练句来源 | 纯本地，不调用 LLM | 降低复杂度，消除幻觉风险，素材句天然真实 |
| 记录存储 | 独立 `vocabtrain:` 前缀 | 与素材训练记录 (`train:`) 隔离，查询不交叉 |
| 干扰项来源 | 同课程内其他生词 | 语义相近、干扰性强、无需额外 API |
| 填空选项数 | 固定 4 项 | 平衡难度与移动端布局 |
| 熟练度模型 | 简单 3 级阶梯（new/familiar/mastered） | MVP 足够，避免 SM-2 复杂度 |
| 空状态处理 | 检索无结果时引导用户导入素材 | 降低困惑，引导正确使用路径 |
| Select 组件 | 新建 `components/ui/select.tsx` | 现有 UI 库中不存在，课程配置页必需 |

## 十一、风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| 素材量大时检索慢 | 首次编排延迟 | 建索引 / 缓存 / 限制扫描范围 |

### SOE
- 定义：口语评测（Speaking-oriented Evaluation）的缩写，指对学习者朗读/跟读发音进行评分的能力。在本项目中通过后端 SOE Provider 注册表抽象，支持 Azure、腾讯云、科大讯飞等多个厂商实现，并由 mock provider 作为默认回退。
- 别名：口语评测、发音评分

### BFF
- 定义：Backend For Frontend 层，在本项目中指基于 Fastify 的后端服务，承担 SOE 发音评分代理、AI 服务契约中转等职责，端口 :8788。
- 别名：BFF layer、Fastify 后端

### Knowledge Cards
- 定义：项目知识体系中的模块级技术笔记，按 kind（module/design/lesson/config）+ category（## 章节）组织，节点用短 id 寻址，通过 IDE 内置的 atlas/Knowledge 图谱工具读写。与 Wiki Articles（项目级长文档）并列，共同构成 `/knowledge` 技能的双存储层。
- 别名：Cards、知识卡片

### Wiki Articles
- 定义：项目知识体系中的项目级长文档，按人类可读标题路径寻址（如 `/项目总览`、`/前端分层架构`），由 IDE 内置 wiki MCP 工具管理。与 Knowledge Cards 互补，前者面向整体架构与设计说明，后者面向模块级要点。
- 别名：Wiki、项目级文档

### atlas
- 定义：IDE 内置的知识索引/图谱数据库，Knowledge Cards 的底层存储。需要先在 IDE 中触发一次构建，否则 `list_knowledge` 返回 `no atlas build for this partition`。
- 别名：知识库索引、知识图谱数据库

### MCP 工具
- 定义：Model Context Protocol 工具，本项目通过两个 builtin MCP server（wiki、knowledge）暴露 JSON-RPC 接口给 LLM 调用，用于读写 Wiki Articles 和 Knowledge Cards。每个工具的 inputSchema 定义在 `mcps/<server>/tools/*.json`。
- 别名：MCP server、JSON-RPC 工具

### 契约编号
- 定义：AI 服务契约的编号语义（①~⑧），用于标识 ASR/SOE/TTS/报告等服务接口。其中 ②⑤⑥⑦⑧ 在当前实现中仍有效，①③④ 已被移除。
- 别名：服务契约编号、contracts 编号

### 种子数据
- 定义：首次加载应用时自动注入到 IndexedDB 的初始材料数据，使空库用户也能立即体验播放器与训练功能。
- 别名：seed、初始材料

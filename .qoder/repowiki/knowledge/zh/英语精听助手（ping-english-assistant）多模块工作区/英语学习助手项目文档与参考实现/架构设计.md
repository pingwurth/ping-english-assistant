本模块为纯文档与参考实现，按主题划分：
- 顶层 Markdown 文档构成项目的权威设计来源：《系统架构设计.md》定义 uni-app 三端 + Fastify 后端的分层拓扑、PlayerController/RecorderController 抽象层、字幕解析器、训练引擎、API 契约（①~⑦）、降级矩阵与里程碑；《技术选型报告.md》给出播放器、跨端框架、ASR/SOE/LLM 的对比与推荐结论；《原型设计.md》与 `生词本设计方案.md`、`生词训练功能设计*.md` 覆盖页面原型与业务方案；`qwen语音生成接入.md` / `qwen语音识别接入.md` / `TencentCloud文本翻译.md` / `发音评分技术选型报告.md` 为专项接入文档。
- `阿里云翻译SDK示例/` 是一个独立的 TypeScript 子包（`package.json` + `tsconfig.json`），基于 `@alicloud/alimt20181012` + `@alicloud/tea-typescript` 封装阿里云机器翻译 SDK，提供可运行的 client.ts 示例，作为后端翻译能力接入的参考实现。
- 文档之间存在明确的引用链：系统架构设计以技术选型报告与原型设计为依据，并在 §1.5「实现校准」中对照当前 `client/`（Next.js SPA）与规划拓扑的差异，代码注释普遍以「真源：docs/系统架构设计.md §X」回链章节，形成「文档 → 代码」单向依赖。

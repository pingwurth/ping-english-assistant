- 页面级组件统一以 `Shell` 包裹器渲染固定头部导航与主区域，并通过可选 `back` 属性控制返回按钮显示。
- 页面标题与副标题通过统一的 `PageIntro` 组件传入 `title`、`eyebrow` 和子节点进行排版。
- 业务状态（播放、录音、提交、导入进度等）以 React `useState` 本地 state 管理，不引入外部状态库。
- 可复用 UI 元素拆分为 `components/ui/` 下的独立小文件（button、card、badge、input、textarea、progress、separator），并由 `study-app.tsx` 按需 import。
- 演示数据以模块顶层常量数组（如 `sentences`、`materials`）形式硬编码，避免在组件内部重复定义。

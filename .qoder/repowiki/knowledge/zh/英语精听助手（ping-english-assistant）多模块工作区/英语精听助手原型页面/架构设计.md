模块是一个独立的 Next.js 16 应用（`package.json` 中 `next: 16.3.0`），采用 App Router 作为根布局：`app/layout.tsx` 通过 `Metadata` 与 `Viewport` 配置站点标题、图标与主题色，并在生产环境注入 `@vercel/analytics`；`app/page.tsx` 仅渲染 `StudyApp` 组件。

路由层使用 `react-router-dom` 的 `<BrowserRouter>` + `<Routes>` 在客户端完成 SPA 式导航（`components/study-app.tsx` 内集中声明所有路径），而非依赖 Next.js File-System Routing；`app/[...slug]/page.tsx` 作为兜底捕获任意路径。

UI 层由 `components/ui/` 下的 shadcn 风格原子组件（Button、Card、Badge、Input、Textarea、Progress、Separator）组成，业务页面统一通过 `Shell` 包裹器渲染顶部导航栏与主内容区，并通过 `PageIntro` 复用标题/eyebrow 排版。

数据层目前全部为硬编码 mock（`sentences`、`materials` 常量），无外部 API 调用；`TranscribePage` 用 `setTimeout` 模拟异步转写流程。

静态资源放在 `public/`，包含多尺寸 favicon、apple-icon 与 placeholder 图片。样式体系基于 Tailwind CSS v4（`postcss.config.mjs` + `tailwindcss: ^4.3.3`），并通过 `class-variance-authority` + `tw-animate-css` 管理变体与动画。

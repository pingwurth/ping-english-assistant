- 对外暴露类 + 工厂函数（如 `WebRecorder` + `createRecorder()`、`HtmlPlayerController` + `createHtmlPlayer()`），由调用方按需 new，便于未来多平台实现切换。
- 所有 DOM/Browser API 访问前做 `typeof window/navigator/document === 'undefined'` 守卫，保证 SSR 安全，不在模块顶层触碰宿主环境。
- 错误采用自定义 Error 子类（`RecorderError` / `RecorderPermissionError` / `RecorderNotStartedError`）并通过 `on(event, cb)` 事件总线派发，而非直接 throw。
- 长生命周期资源（AudioContext、MediaStreamTrack、requestAnimationFrame、setTimeout）在 teardown/cleanup 方法中集中释放，并在 finally 或析构路径确保调用。
- Worker 与主线程通过 `kokoro-protocol.ts` 中定义的 discriminated union 类型进行消息编解码，避免双方互相 import 实现代码。
- 持久化层对失败一律静默降级：IDB 打开失败切换到内存 Map，localStorage 读写失败返回 fallback 值，不向调用方抛出异常。

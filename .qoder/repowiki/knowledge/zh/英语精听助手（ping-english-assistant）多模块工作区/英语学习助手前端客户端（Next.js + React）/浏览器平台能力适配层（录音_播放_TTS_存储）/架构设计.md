模块按能力划分为四个并列子域，均面向上层 `core` 暴露统一接口：
- `recorder.ts`：基于 `getUserMedia` + `MediaRecorder` + `AnalyserNode` 的 `WebRecorder`，输出 16kHz 单声道 WAV Blob，通过事件总线派发 volume/maxreach/error。
- `html-player.ts`：实现 `PlayerController` 接口的 `HtmlPlayerController`，封装 `<audio>/<video>` 元素，处理 seek 落点校准、rAF 高频进度采样与 A-B 循环。
- `kokoro-tts.ts` / `kokoro-worker.ts` / `kokoro-protocol.ts`：主线程门面负责 UI 与 WAV 拼装，Worker 内运行 ONNX Runtime Web (`kokoro-js`)；三者通过 `kokoro-protocol.ts` 中定义的 discriminated union 消息协议通信，模型与音色经 `/api/hf/` 代理走磁盘缓存，避免浏览器侧重复副本。
- `storage/`：`idb.ts` 手写 Promise 化 IndexedDB 封装（materials/blobs/records 三个 store，SSR/隐私模式降级到内存 Map），`prefs.ts` 封装 `localStorage`，`schema.ts` 定义记录结构与前缀 key 生成器，`backup.ts` 编排轻量 JSON 与完整 zip 两种备份格式的导出/导入，复用 `core/backup/*` 的格式与压缩原语。
依赖方向单向向外：本模块依赖 `@/core/audio`、`@/core/player/types`、`@/services/mock/tts`、`@/core/backup/*`，不被同层其他文件反向引用。

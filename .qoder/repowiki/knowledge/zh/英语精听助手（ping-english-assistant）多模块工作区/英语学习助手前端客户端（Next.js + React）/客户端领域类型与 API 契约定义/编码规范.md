- 时间戳统一使用毫秒级 number 类型（createdAt / updatedAt / lastOpenedAt / durationMs / startMs / endMs），而非 Date 对象。
- SSE 事件流采用判别联合类型，以 event 字面量区分 status/token/result/done/error 等分支，data 字段随分支变化。
- 领域实体普遍包含 id: string 主键与 createdAt/updatedAt 时间戳，体现持久化实体的通用骨架。
- 可选扩展字段使用 ? 标记（如 definition、note、reportMarkdown、association、exercises），保持核心字段必填、衍生内容可选。
- 每个文件顶部以 JSDoc 注释标注数据来源（docs/系统架构设计.md §4.1、docs/技术选型报告.md §2.4 等），将类型契约与文档章节一一对应。

模块按业务域拆分为独立文件：api.ts 承载跨域共享的 API 契约（SOE 发音评分、LLM 讲解、TTS 生成、翻译、SSE 事件序列）；material.ts / subtitle.ts 描述学习材料与字幕数据；vocabulary.ts 定义生词本与词条；mnemonic.ts 描述 LLM 生成的助记卡片及其缓存结构；training.ts 聚合五种训练模式（puzzle/dictation/read-aloud/shadowing/recitation）的联合 detail 类型；progress.ts 与 note.ts 分别表达学习进度、收藏与句子笔记。所有类型以纯 TypeScript interface/type 形式导出，不引入运行时逻辑，被上层 store、service、UI 组件共同消费，依赖方向单向向外。

- 所有服务方法签名统一接受可选 AbortSignal，并在入口处通过 throwIfAborted(signal) 立即检查中止状态。
- 异常统一封装为 ApiError(code, message, detail?)，网络失败经 toApiError 归一化，DOMException('AbortError') 映射为 code 'ABORTED'。
- mock 实现通过构造函数 options 注入延迟与随机源（delayImpl / randomImpl / paceScale），使 Node 端测试可注入固定值覆盖 Math.random 与 setTimeout。
- 契约与实现分离：contracts.ts 仅声明接口与共享类型，api/* 与 mock/* 各自实现同一接口，工厂在 index.ts 中按运行模式装配。
- SSE 流式能力以 AsyncGenerator 表达，事件序列遵循 status → token → result → done 约定，错误走 error 事件后终止流。

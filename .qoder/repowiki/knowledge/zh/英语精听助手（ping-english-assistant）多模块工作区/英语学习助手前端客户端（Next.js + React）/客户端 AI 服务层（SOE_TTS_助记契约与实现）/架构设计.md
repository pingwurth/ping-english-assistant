模块以 contracts.ts 为唯一契约边界，集中声明 SoeService / TtsService / MnemonicService 三个接口及 AppServices 聚合类型，所有错误统一通过 ApiError（含 ABORTED / INTERNAL / TEXT_TOO_LONG / SUBTITLE_NOT_FOUND 等 code）表达，并配套 toApiError、throwIfAborted、abortableDelay 等工具。

- 工厂入口 index.ts：getMockServices() 返回完整 MockServices；getServices() 预留 ServiceMode 切换（当前恒走 mock）；getSoeService() 根据 settings 中 provider 动态选择 ApiSoeService 或 MockSoeService。
- api/soe.ts：真实实现，POST /api/soe/evaluate（multipart），由 BFF 转发到上游评分服务。
- mock/soe.ts：确定性伪评分——用 FNV-1a(refText + '#' + durationMs) 作为种子派生 total/accuracy/fluency/integrity 与逐词 phonemes，支持 failRate / latencyMinMs / delayImpl / randomImpl 注入以驱动降级路径测试。
- mock/tts.ts：离线模拟 Kokoro 合成，按 [.!?;:\n] 分句估算时长、生成 SRT 时间轴，并用 core/audio/wav-encoder 合成占位正弦 WAV；内置 LRU 500 条的 taskId→SRT 缓存，未命中抛 'SUBTITLE_NOT_FOUND'。
- mock/mnemonic.ts：直接调用后端 /api/mnemonic（action 路由 card/card_stream/association/exercises/evaluate），其中 generateCardStream 自行解析 SSE event:/data: 行流式产出 AsyncGenerator<MnemonicSseEvent>。

依赖方向单向：api/mock → contracts → types/api & types/mnemonic；上层 stores/页面仅依赖 index.ts 导出的 AppServices，不感知具体实现。

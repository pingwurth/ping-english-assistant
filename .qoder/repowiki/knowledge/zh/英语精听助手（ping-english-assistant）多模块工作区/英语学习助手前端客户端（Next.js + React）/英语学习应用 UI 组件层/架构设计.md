模块按职责分为三层：
- `ui/`：基于 `@base-ui/react` + `class-variance-authority` 的基础原子组件（Button/Card/Input/Badge/Dialog/Sheet/Tabs/Progress/Separator/Switch/Textarea），通过 `cn()` 组合 Tailwind 类名，是上层唯一依赖的视觉原语。
- `shared/`：跨页面的业务级复用组件，如 `shell.tsx`（统一头部导航 + 返回按钮 + `pauseAllMedia`）、`training-session-shell.tsx`（训练页进度外壳 + 完成小结浮层 + `useTrainingMaterial` hook）、`player-parts.tsx`（播放器控制栏/字幕列表）、以及 AI 转写、翻译抽屉、字幕编辑、词汇书选择等对话框/抽屉。
- `pages/`：路由级页面组件，由根 `study-app.tsx` 通过 `react-router-dom` 的 `<Routes>` 装配；`pages/training/` 子目录承载九宫格、听写、跟读评分、影子跟读、全文背诵五种训练模式。

依赖方向单向向下：`pages` → `shared` → `ui`，页面组件再调用 `@/stores/*`、`@/platform/*`、`@/core/*` 等外部领域层，本模块不直接持有业务状态。`study-app.tsx` 在启动时预加载 Kokoro TTS 模型并挂载所有路由，作为整个 UI 的入口。

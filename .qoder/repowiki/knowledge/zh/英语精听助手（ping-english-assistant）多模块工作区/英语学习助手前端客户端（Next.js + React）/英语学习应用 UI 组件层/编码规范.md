- 页面组件统一包裹在 `shared/shell.tsx` 提供的 `Shell` 中，并通过可选 `back` 属性显示返回按钮，同时点击返回前调用 `pauseAllMedia()` 暂停音视频。
- 训练类页面复用 `shared/training-session-shell.tsx` 的 `TrainingSessionShell` 展示 eyebrow + 标题 + n/total 徽标与真实进度条，并使用其导出的 `useTrainingMaterial` hook 读取最近材料与收藏句范围。
- 异步数据加载采用 `let cancelled = false` + IIFE 模式，在 effect 清理函数中置位以忽略卸载后的 setState，避免 React 18 并发下的内存泄漏警告。
- 基础 UI 组件通过 `cva` 定义 `variants`（如 variant/size）并用 `cn(buttonVariants({...}))` 合并 className，对外暴露 `XxxProps & VariantProps<typeof xxxVariants>` 类型。
- 路由级页面以命名导出（如 `export { TrainingCenter }`）而非默认导出，便于在 `study-app.tsx` 中以具名 import 集中注册 `<Route>`。

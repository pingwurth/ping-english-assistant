- 每个子目录通过 `index.ts` 作为统一出口，集中 re-export 该领域的公开 API，内部实现文件按需 import。
- 所有可测逻辑保持纯函数或无 DOM 依赖，通过注入参数（如 `now: number = Date.now()`、`RangeReader`、`PlayerController`）使 Node 环境可直接单测。
- 错误处理采用具名错误类（如 `SubtitleParseError`）或返回 `{ ok: true | false; error }` 的可联合类型，错误消息面向用户可读。
- 二进制协议（WAV、ZIP）通过 `DataView` 小端序手动读写字段，配合常量魔数校验（如 `0x04034b50`、`RIFF`）保证格式正确性。
- 大型数据路径优先流式/零拷贝：ZIP 写侧用 sink 回调逐块写出，读侧基于 `RangeReader` 只拉取中央目录与所需条目，避免整包进 JS 堆。

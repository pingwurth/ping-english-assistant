模块按子目录划分独立领域，每个子目录是一个自包含的纯 TS 包：
- `subtitle/`：以 `index.ts` 为入口，通过正则嗅探自动识别 SRT/LRC，再委派到 `srt.ts` / `lrc.ts` 解析器，并统一输出 `SubtitleData`；`bilingual.ts` 负责中英双语切分，`timestamp.ts` 提供时间戳互转。
- `player/`：`sentence-player.ts` 基于抽象 `PlayerController` 接口（见 `types.ts`）实现句级播放控制，封装 A-B 循环（±120ms 容差）、区间播放、二分定位当前句，并通过内部事件总线向调用方派发 `sentencechange/timeupdate/statechange/ended/error`。
- `training/`：`session.ts` 暴露纯函数式状态机（`createSession` + `submit/hint/next/skip/retryAt`），`puzzle.ts` / `dictation-diff.ts` / `scoring.ts` 分别处理九宫格、听写差异与评分，`index.ts` 统一导出。
- `backup/`：`zip.ts` 手写 ZIP 容器读写（仅依赖 `fflate` 做 deflate/inflate），支持流式写入与基于 `RangeReader` 的中央目录索引 + STORE 条目零拷贝读取；`backup-format.ts` 定义 `ParsedBackup` 结构与导入冲突策略（`skipExisting` / `overwrite`）。
- `audio/wav-encoder.ts`：按 ADR-5 将 Float32 PCM 编码为标准 RIFF WAV（16kHz 单声道 16bit）。

依赖方向单向向外：本层不依赖 React/DOM，仅通过 `@/types/subtitle`、`@/types/training` 等上层类型契约被 UI 层引用；测试位于各子目录的 `__tests__/` 下，可在 Node 直接运行。

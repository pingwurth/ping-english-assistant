客户端按分层解耦组织：`app/` 提供 Next.js 页面与 BFF 路由（代理 HF/TTS/设置等），`components/` 为 React UI 层，`core/` 是零框架依赖的业务引擎（字幕解析、句子播放器、训练会话、ZIP 备份、WAV 编码），`platform/` 封装浏览器端录音、HTMLMediaElement 播放、Kokoro-82M 本地 TTS 与 IndexedDB/localStorage 持久化，`services/` 定义 SOE/TTS/助记三类 AI 服务的统一接口契约并提供 mock 与 api 两种可插拔实现，由 `services/index.ts` 的 `getServices()` / `getMockServices()` 工厂在运行时切换；`stores/` 基于 useSyncExternalStore 暴露领域数据订阅，`types/` 集中所有领域模型与 API 契约作为唯一真源。UI 层通过 stores 订阅状态、通过 services 调用 AI 能力、通过 core 处理纯逻辑、通过 platform 访问浏览器原生能力，BFF 路由则把外部请求转发到远端或本地 Kokoro 推理。

模块遵循 Next.js App Router 约定：
- `layout.tsx` 定义全局 `<html>`、SEO metadata、viewport 与生产环境 `@vercel/analytics` 注入，是所有页面的根壳。
- `page.tsx` 与 `[...slug]/page.tsx` 是 SPA 入口，直接渲染 `@/components/study-app`，通过 catch-all 路由让前端路由接管所有路径。
- `api/` 下按功能域组织 Route Handlers（`transcribe`、`tts`、`settings/*`、`hf/[...path]`、`mnemonic`、`models`、`soe/*`、`translate/*`），每个 handler 仅做请求解析与响应封装，业务逻辑下沉到 `@/lib/server-settings`、`@/lib/llm`、`@/services/mock/tts` 等库层。
- `api/hf/[...path]/route.ts` 实现 HuggingFace 模型文件的磁盘缓存代理：GET 命中本地 `modelPath/{org}--{repo}/{file}` 直接返回，未命中则经 `undici` + 可选 `https_proxy` 拉取上游并落盘；HEAD 仅探测磁盘以区分 HIT/MISS，同时用 `detectBadPayload` 拦截 LFS 指针与 HTML 错误页防止污染缓存。
- 依赖方向单向：Route Handler → `@/lib/*`（server-settings、llm、service-endpoints）→ 外部 HTTP 上游，不反向引用组件层。

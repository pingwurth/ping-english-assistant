- API Route Handler 统一使用 `NextResponse.json({ error, ... })` 返回结构化 JSON，并在 catch 分支中区分 `LlmError` 与普通 Error 以保留错误码。
- 需要持久化配置的接口通过 `readLlmSettings` / `writeLlmSettings` / `readLlmConfigById` 访问 `@/lib/server-settings`，而非直接读写环境变量或文件。
- ASR/TTS 等对外部 AI 服务的调用委托给 `@/lib/llm` 中的 `transcribe` / `generateTts`，路由层只负责参数组装与结果后处理，避免在 handler 内写 provider 分支。
- HF 模型下载采用 HEAD 探测 + GET 落盘的两次往返模式，并通过 `X-Cache: HIT|MISS` 头向客户端暴露缓存状态。

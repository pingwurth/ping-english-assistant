模块以 `store.ts` 暴露的 `createStore` + `useStore` 为内核：`createStore` 维护一个闭包 state 与 listener Set，提供 `get/set/subscribe` 三方法；`useStore` 通过 React 的 `useSyncExternalStore` 订阅，第三个参数传 `store.get` 实现 SSR 安全。

各业务 store（material-store / vocab-store / mnemonic-store / favorite-store / note-store）遵循统一分层：
- 持久化层：全部通过 `@/platform/storage/idb` 的 `materialsStore` / `recordsStore` / `blobsStore` 访问 IndexedDB，key 由 `RECORD_KEYS` 生成，按前缀（`fav:` / `note:` / `vocabbook:` / `vocabentry:` / `collection:` / `train:` / `progress:` / `mnemonic:`）隔离命名空间。
- 内存状态层：用 `createStore` 创建轻量 store（如 `materialStore`、`vocabStore`、`mnemonicStore`），仅缓存需要响应式刷新的数据（ready 标志、列表、缓存字典）。
- 初始化幂等：material/vocab 通过 `initPromise ??= ...` 保证首次加载只执行一次，并在其中注入种子数据或默认集合。
- 级联清理：删除材料时集中处理 blob、progress/fav/note/train 相关 records；删除生词本时级联删词条；删除句子时调用 `shiftNotesAfterDeletion` 平移后续笔记序号。

依赖方向单向向外：stores → platform/storage → types，不反向引用 UI 组件。

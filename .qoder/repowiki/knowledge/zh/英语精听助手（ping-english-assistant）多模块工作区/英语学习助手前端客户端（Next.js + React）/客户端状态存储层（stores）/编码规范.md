- 每个业务 store 文件顶部注释声明其持久化 key 前缀（如 `fav:`、`note:`、`vocabbook:`），并说明跨模块职责边界。
- 所有 IndexedDB 访问放在异步函数内，同步函数仅读取内存 store，以保证 SSR 安全。
- CRUD 操作先 `await initXxx()` 确保初始化完成，再执行业务逻辑，最后 `await refresh()` 广播状态变更。
- 对外导出的是纯函数 API（如 `listFavorites`、`saveSentenceNote`、`createBook`），而非直接暴露 store 实例。
- 批量写操作使用 `Promise.all` 并行提交，读操作对 `allKeys()` 结果做 `startsWith(prefix)` 过滤后再并发 `get`。

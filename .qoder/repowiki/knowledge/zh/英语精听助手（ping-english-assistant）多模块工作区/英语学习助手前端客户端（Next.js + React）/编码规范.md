- AI 服务通过 `services/contracts.ts` 定义的接口抽象，并由 `services/index.ts` 的工厂函数返回 mock 或 api 实现，上层不直接感知后端来源。
- 领域类型集中在 `types/` 下，UI 层与服务层均从该目录引用，避免重复声明。
- 纯业务逻辑放在 `core/` 子目录（audio/subtitle/training/backup/markdown/player），保持零框架依赖以便独立测试。
- 浏览器原生能力（录音、TTS、IndexedDB、localStorage）统一收敛在 `platform/`，对上层暴露稳定接口。
- 状态管理使用 `useSyncExternalStore` 实现的 store 文件，UI 组件通过订阅而非命令式更新消费数据。

仓库按职责拆分为四个子模块：`client/` 是主工程（Next.js App Router 仅作为 SPA shell，react-router-dom 管理 14 条客户端路由），通过 `app/api/*` Route Handlers 充当 BFF，读取 `~/.ping-eng/settings.json` 并转发到上游；`server/` 同时承载 Python FastAPI（faster-whisper 转写 :8766、WhisperX 对齐 :8765）和 Node.js Fastify SOE 发音评分代理 (:8788)，对外暴露 `POST /api/v1/soe/evaluate`；`page_prototype/` 是独立的 Next.js 设计沙箱，拥有自己的 `package.json` 与依赖树，不影响主工程；`docs/` 存放系统架构设计、技术选型报告等中文参考文档。

跨模块协作契约集中在 `client/services/contracts.ts`（AI 服务接口）与 `docs/系统架构设计.md`（编号②⑤⑥⑦⑧ 的 API 契约与数据模型），BFF 层在 `lib/service-endpoints.ts` 集中维护端点路径与默认服务地址，避免各处硬编码 baseUrl。音频链路统一为 `getUserMedia → MediaRecorder → OfflineAudioContext(16kHz mono) → WAV Blob`，确保 ASR/SOE 兼容性。状态全部落浏览器 IndexedDB（`platform/storage/idb.ts` 手写 Promise wrapper），后端保持无状态。

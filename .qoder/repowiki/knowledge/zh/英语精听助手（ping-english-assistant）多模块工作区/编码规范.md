- 代码注释、commit message 与设计文档统一使用中文（zh-CN）。
- 路径别名 `@/*` 指向 `client/` 根目录，在 tsconfig.json 与 vitest.config.mts 中同步配置。
- AI 服务通过 `services/contracts.ts` 定义接口、`services/mock/` 提供 mock 实现、`services/api/` 实现 BFF 调用，当前工厂始终返回 mock。
- UI 组件基于 shadcn/ui base-nova 主题，样式走 Tailwind utility + `lib/utils.ts` 的 `cn()` 合并 helper。
- 状态管理采用自研 `createStore` + `useSyncExternalStore`，不引入 zustand/Pinia 等第三方库。
- 测试文件与源码同目录放在 `__tests__/` 下，仅覆盖纯 TS 的 core/ 与 services/mock/，不在浏览器或 React 环境中运行。

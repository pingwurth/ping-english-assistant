# 前端分层架构

> 对象：`client/`。依赖方向单向向下，`core/` 保持可在 Node 环境直接跑单测。

## 1. 分层与落点

```
app/          Next.js App Router —— 仅作 SPA shell + BFF Route Handlers
components/   pages/（页面组件）· pages/training/ · shared/（业务复用组件）· ui/（shadcn 原子）
stores/       自研 store（createStore + useSyncExternalStore）
services/     AI 服务契约 + mock 实现 + BFF 客户端实现
lib/          浏览器/服务端共用工具；lib/llm 为 BFF 侧 LLM 适配
platform/     浏览器专属实现（播放、录音、Kokoro worker、IndexedDB/prefs/备份）
core/         平台无关纯 TS（字幕、训练算法、播放器抽象、WAV 编码、备份、Markdown）
types/        业务与契约类型定义
```

`core/` 不 import React、不访问 DOM/IndexedDB，因此 `pnpm test`（vitest, node env）能直接覆盖它。**测试只写 core 层与 services 层的纯逻辑**，放在同目录 `__tests__/` 下；仓库内没有任何 React/浏览器测试，不要试图补组件测试基础设施。

## 2. SPA shell 的路由真相

Next.js 只承担两条路径：`app/page.tsx` 与 `app/[...slug]/page.tsx`，两者都渲染 `components/study-app.tsx`。真正的路由是 `react-router-dom` 的 `BrowserRouter`，当前 17 条路由：

`/`（材料库）· `/collection/:collectionId` · `/favorites` · `/import` · `/player/:materialId` · `/training/:materialId` · `/training/{puzzle,dictation,read-aloud,shadowing,recitation}` · `/settings` · `/transcribe` · `/tts` · `/vocabulary` · `/vocabulary/mnemonic/:entryId` · `*`（Placeholder）

所有页面组件都是 `'use client'`，业务逻辑无 SSR。`StudyApp` 挂载时会 `fetch('/api/settings/kokoro')` 拿到模型 ID 并 `preloadKokoroModel()`，这是应用启动的副作用入口。

**改路由只改 `study-app.tsx`**；`app/[...slug]/page.tsx` 的 catch-all 保证任意深链都能进 SPA。

## 3. 播放器抽象（core/player + platform/html-player）

- `core/player/types.ts` 定义 `PlayerController` 接口（load/play/pause/seekTo/setRate/setVolume/setLoop/clearLoop/getCurrentTimeMs/getDurationMs/getState/on/off/destroy），沿用架构文档 ADR-1 的形状；事件集 `PlayerEvents{timeupdate,statechange,ended,error}`。
- `core/player/sentence-player.ts`（218 行）组合 `PlayerController` + `SubtitleData`，提供 `playSentence / next / prev / loopSentence / locateSentence`（按 `startMs` 二分定位当前句）与 `onSentenceChange`（index 变化才派发，避免高频重渲染）；循环边界容差常量 `LOOP_TOLERANCE_MS = 120`。
- `platform/html-player.ts` 的 `HtmlPlayerController` 是浏览器唯一实现（`createHtmlPlayer(kind, element?)`），原生 `timeupdate` 约 4Hz，用 `rAF` 补偿至接近 60Hz 驱动进度条。
- **seek 漂移补偿必须保留**：`SEEK_DRIFT_THRESHOLD_MS = 300`，seek 后若实际落点偏差超阈值则以实际落点修正循环边界。这是架构文档 §5.1 的等价实现，删掉会导致单句循环越过边界漏触发。

## 4. 录音与音频（platform/recorder + core/audio）

`getUserMedia → MediaRecorder → OfflineAudioContext 重采样 → 16kHz 单声道 WAV`，由 `core/audio/wav-encoder.ts` 编码（导出 `TARGET_SAMPLE_RATE = 16000`、`encodeWav(Float32Array, sampleRate?)`、`wavDurationMs()`、`WAV_MIME`）。固定 16kHz mono 是架构 ADR-5 的落地：同一份录音既能喂 ASR（Qwen/MiMo/本机 faster-whisper）也能喂 SOE 评分，不需要多套录音配置，也不需要后端 ffmpeg 转码。

`platform/recorder.ts` 导出 `WebRecorder` / `createRecorder()`，并把失败分型为 `RecorderError` → `RecorderPermissionError`（麦克风被拒）/ `RecorderNotStartedError`，页面按类型给不同提示。

## 4b. 训练引擎（core/training）

| 文件 | 对外能力 | 注意 |
|------|----------|------|
| `session.ts` | `createSession(mode, sentences, scope)` + `submit/next/hint/skip/currentSentence/makeRecordId` + `sentencesInScope()` | 纯函数状态机，事件迁移返回新对象；范围过滤统一在此 |
| `dictation-diff.ts` | `normalize` / `toWords` / `diffWords`（逐词 LCS → `DiffToken{type}`）/ `sentenceAccuracy` | token 四型 `correct\|wrong\|missing\|extra` 供 UI 着色 |
| `puzzle.ts` | 线性 `buildTiles/checkAnswer/nextHint/puzzleScore` + 九宫格 `GRID_SIZE=9`、`initGridState/selectGridWord/getGridHint/gridScore/collectDistractorWords` | **两套并存**，改前先确认页面走哪套 |
| `scoring.ts` | `summarize(results, durationMs) → SessionSummary`、`formatElapsed()` | 是**训练小结**加工，不是 SOE 分数加工（见 `/开发指南与项目陷阱` §4） |

`core/` 另含 `markdown/note-markdown.ts`（句子笔记 ↔ Markdown）与 `backup/`（备份格式 + zip 读写，依赖 `fflate`）。

## 5. 状态层

`stores/store.ts` 是 34 行的零依赖实现：`Store<T> = { get, set, subscribe }`，`useStore` 内部走 `useSyncExternalStore(subscribe, get, get)`（第三个参数让 SSR 安全）。

现有 store：`material-store`（材料 + 材料集 + 种子注入）、`favorite-store`、`note-store`、`vocab-store`（生词本/词条）、`mnemonic-store`（助记卡片）。

共同模式：**store 本体是普通 JS 对象，异步函数读写 IndexedDB 后调用 `refresh()` 广播**。浏览器 API 只出现在异步函数里，由 `useEffect`/事件回调触发，从而保持 SSR 安全。`initMaterials()` 用 `initPromise ??=` 做幂等初始化。

禁止引入 zustand/Pinia（`AGENTS.md` 明确约束）。

## 6. UI 约定

- shadcn/ui（base-nova 风格，底层 `@base-ui/react`）+ Lucide 图标 + Tailwind 4 工具类。
- 类名合并统一走 `lib/utils.ts` 的 `cn()`（clsx + tailwind-merge）。
- `ui/` 实际原子：badge、button、card、dialog、input、progress、separator、sheet、switch、tabs、textarea。
- 页面/组件内注释、文档、提交信息一律中文（zh-CN）。
- 无 ESLint / Prettier 配置，遵循现有代码风格即可。

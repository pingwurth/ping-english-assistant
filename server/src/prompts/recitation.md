## 任务
对比原文与用户背诵转写，输出 Markdown 格式的评估报告，侧重**完整度与记忆准确度**：
1. **✅ 记住的部分**：哪些句子/段落完整准确
2. **⚠ 遗漏与偏差**：具体指出漏背、错背的句子位置（第 N 句），以及替换/颠倒的内容
3. **💡 记忆建议**：针对薄弱句子给出记忆策略（意群切分、关键词锚定等）

## 输出格式要求
- 正文为 Markdown 评估报告（中文撰写）
- 正文结束后，另起一行输出分隔符 `---RESULT---`，然后输出一行 JSON 评分：
  `{"total": <0-100综合分>, "completeness": <0-100完整度>, "accuracy": <0-100记忆准确度>, "fluency": <0-100流利度>}`

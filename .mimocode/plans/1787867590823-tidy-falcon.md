# Transcribe → Import: Auto-carry audio + subtitle

## Problem

The "导入为学习材料" button on `/transcribe` is a plain `<Link to="/import">`. It does not pass the source audio file or generated SRT to the import page — the user must re-select both files manually. The TTS page already solves this pattern via `tts-export.ts` (IDB + sessionStorage bridge).

## Design

Mirror the TTS-to-import bridge:

1. **New bridge module** `client/lib/transcribe-export.ts` — stores audio File as Blob in IDB (`tts:`-style key) and SRT metadata in sessionStorage. Three functions: `writeTranscribeExport`, `readTranscribeExport`, `consumeTranscribeExport`.

2. **TranscribePage** — replace `<Link to="/import">` with an `onClick` handler that calls `writeTranscribeExport(taskId, audioFile, srtText, fileName)` then navigates to `/import?source=transcribe&taskId={taskId}`.

3. **ImportPage** — add `?source=transcribe` handling in the existing `useEffect` block (alongside the `?source=tts` block), calling `readTranscribeExport` to auto-fill media file and subtitle.

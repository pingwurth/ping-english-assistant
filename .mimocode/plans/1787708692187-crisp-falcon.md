# Plan: 支持 MiMo ASR（mimo-v2.5-asr）音频转字幕

## 问题根因

当前 `client/app/api/transcribe/route.ts` 使用 OpenAI Whisper 的 `/audio/transcriptions` 端点（multipart form-data），但 MiMo 的 ASR 模型（`mimo-v2.5-asr`）**不支持该端点**。

根据 MiMo 官方文档，`mimo-v2.5-asr` 使用 **`/chat/completions` 端点**，音频以 base64 编码通过 `input_audio` content block 传入，格式与 OpenAI Whisper API 完全不同。

## 修改方案

### 1. 添加 MiMo 为预置 Provider

**文件**: `client/components/shared/llm-settings-dialog.tsx`

- 在 `PROVIDERS` 数组中添加 MiMo 选项：
  ```ts
  { value: 'mimo', label: 'Xiaomi MiMo', defaultBaseUrl: 'https://api.xiaomimimo.com/v1' }
  ```
- 默认模型自动填充为 `mimo-v2.5-asr`（当 provider 为 mimo 时）
- 端点路径提示改为：MiMo 使用 `/chat/completions`，无需自定义

### 2. 修改 transcribe API route 支持 MiMo ASR

**文件**: `client/app/api/transcribe/route.ts`

添加 MiMo 分支逻辑：

```ts
// 检测是否为 MiMo ASR
function isMimoAsr(settings: LlmSettings): boolean {
  return settings.provider === 'mimo' || 
         settings.baseUrl.includes('xiaomimimo.com') ||
         (settings.model || '').startsWith('mimo')
}
```

**MiMo ASR 路径** (当 `isMimoAsr()` 为 true):
- 将音频 File 转为 base64 编码
- 推断 MIME 类型（wav → `audio/wav`，mp3 → `audio/mpeg`）
- POST 到 `{baseUrl}/chat/completions`（而非 `/audio/transcriptions`）
- 请求体格式：
  ```json
  {
    "model": "mimo-v2.5-asr",
    "messages": [{
      "role": "user",
      "content": [{
        "type": "input_audio",
        "input_audio": {
          "data": "data:{mime};base64,{base64data}"
        }
      }]
    }],
    "extra_body": {
      "asr_options": { "language": "auto" }
    }
  }
  ```
- 响应解析：从 `choices[0].message.content` 获取转写文本
- 注意：MiMo ASR 非流式返回可能不包含 timestamps/segments，此时创建单个 segment

**OpenAI Whisper 路径**: 保持现有逻辑不变。

### 3. 前端端点字段提示更新

**文件**: `client/components/shared/llm-settings-dialog.tsx`

- 当选择 MiMo provider 时，端点路径 placeholder 改为 `/chat/completions`（或自动隐藏该字段，因为 MiMo 无需自定义端点）
- 添加说明文字提示 MiMo 使用不同的 API 格式

### 涉及文件清单

| 文件 | 修改类型 |
|------|---------|
| `client/app/api/transcribe/route.ts` | 核心：添加 MiMo ASR 分支逻辑 |
| `client/components/shared/llm-settings-dialog.tsx` | UI：添加 MiMo provider、更新提示 |
| `client/lib/server-settings.ts` | 可能：`LlmSettings` 接口无需修改（已有 provider 字段） |

## 验证方式

1. 在设置对话框中选择 "Xiaomi MiMo" provider，确认 Base URL 自动填充为 `https://api.xiaomimimo.com/v1`
2. 填入 API Key，选择 `mimo-v2.5-asr` 模型
3. 上传一段 wav/mp3 音频，调用大模型转写
4. 确认请求发送到 `/chat/completions` 而非 `/audio/transcriptions`
5. 确认返回的转写文本正确显示并生成 SRT 字幕

# Plan: Fix "开始转换" Button Disabled Despite Model Configuration

## Root Cause

The "开始转换" button's disabled condition (`transcribe.tsx:81`, `ai-transcribe-dialog.tsx:76`) is:

```ts
disabled={!file || method === 'third-party'}
```

**The button has TWO requirements to be clickable:**
1. A file must be selected (`!file` → false)
2. The method must NOT be 'third-party' (`method === 'third-party'` → false)

**The problem:** The default method in `useTranscribe()` (`transcribe-shared.tsx:81`) is:

```ts
const [method, setMethod] = useState<Method>('third-party')
```

So even after configuring the model in `settings.json`, the button stays disabled because:
- The default method is 'third-party', which explicitly disables the button
- The model configuration in settings.json is NOT checked for the button's disabled state — it's only checked at runtime inside `start()` when the user clicks

**In summary:** Configuring the model has zero effect on the button's enabled/disabled state. The user must also manually switch the method from "第三方工具" to "调用大模型" AND upload a file.

## Fix

**File:** `client/components/shared/transcribe-shared.tsx`

Change the default method logic in `useTranscribe()` to auto-detect the best available method:

```ts
// Current (line 81):
const [method, setMethod] = useState<Method>('third-party')

// Proposed: initialize asynchronously based on LLM config
const [method, setMethod] = useState<Method>('third-party')
```

Replace with a lazy initialization that checks if LLM is configured on mount:

```ts
const [method, setMethod] = useState<Method>('local')
```

Then add a `useEffect` to check LLM configuration and auto-select 'model' if configured:

```ts
useEffect(() => {
  checkLlmConfigured().then(ok => {
    if (ok) setMethod('model')
  })
}, [])
```

This way:
- If LLM is configured → default to 'model' (button only needs a file)
- If LLM is NOT configured → default to 'local' (button only needs a file)
- 'third-party' is never the default (user can still select it manually)

The button will become clickable as soon as a file is selected, without requiring the user to also manually switch methods.

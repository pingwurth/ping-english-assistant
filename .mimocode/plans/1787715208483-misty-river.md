# Plan: 修复大模型转写无时间戳问题

## 问题根因

`client/app/api/transcribe/route.ts` 中的 `transcribeMimo` 函数（第 84-92 行）：

```typescript
const text = result.choices?.[0]?.message?.content || ''
return NextResponse.json({
    text,
    durationMs: 0,
    segments: text ? [{ startMs: 0, endMs: 0, text: text.trim() }] : [],
})
```

MiMo ASR 通过 `/chat/completions` 返回纯文本，**不含时间戳**。当前代码创建单个 segment（startMs=0, endMs=0），导致 `segmentsToSrt()` 生成的 SRT 为：

```
1
00:00:00,000 --> 00:00:00,000
<全部文字堆在一起>
```

这不是有效的字幕文件——没有分句、没有时间轴，无法导入播放器。

## 解决方案

**核心思路**：当 ASR 返回的文字没有时间戳时，服务端自动进行"分句 + 按时长分配时间戳"后处理。

### 实现步骤

#### 1. 添加音频时长解析工具函数

**文件**: `client/app/api/transcribe/route.ts`

添加两个辅助函数：

```typescript
/** 从 WAV 文件头精确解析时长 */
function probeWavDurationMs(buf: ArrayBuffer): number | null

/** 估算音频时长：WAV 精确解析，MP3 按文件大小估算 */
async function estimateAudioDurationMs(audioFile: File): Promise<number>
```

逻辑复用 `client/services/mock/asr.ts:27-55` 的 WAV 解析代码（逐 chunk 定位 data），MP3/M4A 按 128kbps 估算。

#### 2. 添加文本分句 + 时间戳分配函数

**文件**: `client/app/api/transcribe/route.ts`

```typescript
function splitIntoSentences(text: string): string[]

function distributeTimestamps(
  sentences: string[],
  totalDurationMs: number
): AsrTranscribeSegment[]
```

分句逻辑：
- 按 `.` `!` `?` 分句
- 过长句子（>100字符）在 `,` `;` 处二次拆分
- 过短片段合并到前一句

时间戳分配：
- 按各句 **单词数占比** 等比分配总时长
- 保证每句 startMs = 上一句 endMs（无缝衔接）

#### 3. 修改 `transcribeMimo` 使用后处理

**文件**: `client/app/api/transcribe/route.ts` 第 84-92 行

```typescript
// 原来：
segments: text ? [{ startMs: 0, endMs: 0, text: text.trim() }] : [],

// 改为：
const durationMs = await estimateAudioDurationMs(audioFile)
const sentences = splitIntoSentences(text)
const segments = distributeTimestamps(sentences, durationMs)
```

#### 4. 同样修复 `transcribeWhisper` 的 fallback 路径

**文件**: `client/app/api/transcribe/route.ts` 第 164-170 行

当 Whisper 也不返回 segments 时，同样使用后处理逻辑（而非回退到单段 0:00）。

仅需修改 **1 个文件**，改动约 80-100 行。

## 验证方式

1. 配置 MiMo ASR provider（或任何不返回时间戳的 provider）
2. 上传一段音频，点击"调用大模型"转写
3. 确认生成的 SRT 包含多个分句，每句有合理的时间戳（而非全部 0:00:00）
4. 确认 SRT 可正常导入播放器，字幕随音频播放逐句高亮
5. 用 Whisper provider 转写同一段音频，确认原有带时间戳的流程不受影响

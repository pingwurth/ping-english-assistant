# 修复：Player 字幕切换时容器高度抖动

## 根因

字幕显示区使用 `flex min-h-72 flex-1 flex-col justify-end`（player.tsx:210），
`flex-1` 让容器随内容伸缩，不同句子文本行数不同导致容器高度时大时小，
整条左栏高度跟随变化 → grid 高度变化 → 页面抖动。

## 修改方案

**文件**: `client/components/pages/player.tsx` (line 210)

将字幕显示区的外层容器从：
```
flex min-h-72 flex-1 flex-col justify-end rounded-3xl bg-primary p-6 shadow-inner md:min-h-[480px]
```
改为：
```
flex h-[40vh] min-h-72 flex-col justify-end rounded-3xl bg-primary p-6 shadow-inner md:h-[50vh]
```

关键变化：
- 移除 `flex-1`（它让容器随内容伸缩，是抖动的根源）
- 添加 `h-[40vh]` / `md:h-[50vh]` 设定固定视窗高度，确保容器高度不随内容变化
- 保留 `min-h-72` 作为小屏兜底

这样内容卡片始终贴底显示在固定高度容器内，切换字幕时只有文字内容变化，容器高度不变。

## 验证

1. `bun dev` 启动开发服务器
2. 打开任意有字幕的材料播放页面
3. 连续点击下一句/上一句（或自动播放），观察左栏字幕区是否还有高度跳动
4. 测试不同屏幕宽度（移动端 / md / lg）下布局正常

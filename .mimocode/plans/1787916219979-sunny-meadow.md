# Plan: 给 player.tsx 的 AI 转写弹窗添加翻译开关和翻译模型选择

## Problem

Player 页面的 AI 转字幕弹窗 (`ai-transcribe-dialog.tsx`) 缺少翻译开关和翻译模型选择下拉框，而独立的转写页面 (`transcribe.tsx`) 已有这些功能。

**根本原因**：两者都使用 `useTranscribe()` hook（来自 `transcribe-shared.tsx`），该 hook 已返回所有翻译相关状态，但 `ai-transcribe-dialog.tsx` 没有解构使用它们。

## 代码复用分析

**完全可以复用。** `useTranscribe()` hook 已经包含全部翻译逻辑：

- `translateEnabled` / `setTranslateEnabled` — 翻译开关状态
- `translateConfigs` / `selectedTranslateConfigId` / `setSelectedTranslateConfigId` — 翻译模型配置
- `translateWarning` — 翻译警告信息
- 内部的 `applyTranslation()` 会自动使用这些状态生成双语 SRT

只需在 `ai-transcribe-dialog.tsx` 中解构这些变量并渲染 UI，无需任何新逻辑。

## 修改文件

### `client/components/shared/ai-transcribe-dialog.tsx`

1. **导入 `Switch` 组件**：
   ```tsx
   import { Switch } from '@/components/ui/switch'
   ```

2. **解构翻译相关状态**（从 `useTranscribe()` 返回值中补充）：
   ```tsx
   translateEnabled,
   setTranslateEnabled,
   translateConfigs,
   selectedTranslateConfigId,
   setSelectedTranslateConfigId,
   translateWarning,
   ```

3. **添加翻译 UI**（在 `MethodHint` 之后、状态按钮之前，与 `transcribe.tsx` L116-141 一致）：
   ```tsx
   {(method === 'model' || method === 'local') && (
     <div className="flex flex-col gap-2 rounded-xl bg-muted p-4">
       <div className="flex items-center gap-2">
         <span className="text-sm font-medium">翻译</span>
         <Switch
           checked={translateEnabled}
           onCheckedChange={setTranslateEnabled}
           aria-label="翻译开关"
         />
         {translateEnabled && (
           <select
             value={selectedTranslateConfigId || ''}
             onChange={e => setSelectedTranslateConfigId(e.target.value)}
             disabled={translateConfigs.length === 0}
             className="rounded-md border border-input bg-background px-2 py-1 text-xs disabled:opacity-50"
           >
             {translateConfigs.map(c => (
               <option key={c.id} value={c.id}>{c.translateModel} · {c.name}</option>
             ))}
           </select>
         )}
       </div>
       {translateEnabled && translateConfigs.length === 0 && (
         <p className="text-xs text-destructive">请先在「设置 → 模型配置」中配置翻译模型</p>
       )}
     </div>
   )}
   ```

4. **在结果区域添加翻译警告**（`TranscribeResult` 之前）：
   ```tsx
   {translateWarning && (
     <div className="rounded-xl border border-yellow-500/40 bg-yellow-500/10 p-3 text-sm text-yellow-700 dark:text-yellow-400">
       {translateWarning}
     </div>
   )}
   ```

## 不需要修改的文件

- `transcribe-shared.tsx` — hook 已返回全部翻译状态，无需改动
- `player.tsx` — 不涉及，弹窗逻辑全在 `ai-transcribe-dialog.tsx`
- `lib/translate.ts` — 纯工具库，已被 hook 内部使用
- `lib/pref-keys.ts` — 偏好持久化，dialog 中不需要（保持与页面一致：dialog 每次打开默认关闭翻译）

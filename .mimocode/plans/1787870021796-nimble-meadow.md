# Fix: API Key "留空则不修改" 逻辑冲突 + 回填与显隐

## Problem

编辑模型配置时，API Key 输入框提示"留空则不修改"，但保存时前端校验要求 `apiKey` 必填，导致留空无法保存。同时编辑时 API Key 不回填，体验差。

## Fix (3个文件)

### 1. 前端 `client/components/pages/settings.tsx`

**a) 导入 Eye/EyeOff 图标**（line 15）:
```diff
- import { ChevronDown, Database, ... Trash2 } from 'lucide-react'
+ import { ChevronDown, Database, Eye, EyeOff, ... Trash2 } from 'lucide-react'
```

**b) 新增 `showApiKey` state + 编辑时回填 masked key**（~line 287-325）:
- 新增 state: `const [showApiKey, setShowApiKey] = useState(false)`
- 编辑时回填: `setApiKey(editingConfig.apiKey || '')` （API 返回的已经是 masked 格式 `前8字符***`）
- 重置时: `setShowApiKey(false)`

**c) API Key 输入框改为密码+眼睛图标**（~line 440-449）:
```tsx
<div className="relative">
  <Input
    type={showApiKey ? 'text' : 'password'}
    placeholder={isEdit ? '留空则不修改' : 'sk-...'}
    value={apiKey}
    onChange={e => { setApiKey(e.target.value); setModels([]) }}
    className="pr-10"
  />
  <button
    type="button"
    onClick={() => setShowApiKey(!showApiKey)}
    className="absolute right-2 top-1/2 -translate-y-1/2 text-muted-foreground hover:text-foreground"
  >
    {showApiKey ? <EyeOff className="size-4" /> : <Eye className="size-4" />}
  </button>
</div>
```

**d) `handleSave` 校验逻辑**（line 354-385）:
```diff
- if (!baseUrl.trim() || !apiKey.trim()) { setError('Base URL 和 API Key 是必填的'); return }
+ if (!baseUrl.trim()) { setError('Base URL 是必填的'); return }
+ if (!isEdit && !apiKey.trim()) { setError('API Key 是必填的'); return }
```

编辑时，如果 apiKey 是 masked 格式（含 `***`）或为空，请求体里不传 apiKey:
```diff
  const body = {
    ...
-   apiKey: apiKey.trim(),
+   // 编辑模式：masked key 或空值不传，后端保留原值
+   ...((!isEdit || (apiKey.trim() && !apiKey.includes('***')))
+     ? { apiKey: apiKey.trim() } : {}),
    ...
  }
```

### 2. 后端 `client/lib/server-settings.ts`

`updateLlmConfig`（line 146-162），过滤掉空/undefined `apiKey` 防止覆盖:

```diff
- configs[idx] = { ...configs[idx], ...patch, id }
+ const { apiKey: patchKey, ...rest } = patch as Record<string, unknown>
+ const safePatch = patchKey ? { ...rest, apiKey: patchKey } : rest
+ configs[idx] = { ...configs[idx], ...safePatch, id }
```

## Files to modify

- `client/components/pages/settings.tsx` — 导入图标、state、回填、输入框 UI、校验逻辑
- `client/lib/server-settings.ts` — `updateLlmConfig` 防空值覆盖

4. 编辑配置：不修改 API Key → 保存成功，原 Key 保留
